# Cars Gold

**Automotive Website and Digital Solutions**

[Visit Cars Gold](https://carsgold.co.za)

## About the Project

Cars Gold is an automotive digital platform developed to support online vehicle discovery, customer enquiries and digital automotive business operations.

The project demonstrates practical web development, business-focused application development and the use of technology to improve customer experiences in the automotive industry.

## Key Features

- Automotive business website.
- Online vehicle information and listings.
- Customer enquiry functionality.
- Digital business workflows.
- Responsive website experience.
- Website maintenance and ongoing improvements.

## Technology Stack

- HTML
- CSS
- JavaScript
- Base44 backend and database
- AI-assisted development
- API integration
